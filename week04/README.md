-4주차 네트워크

-공인 IP: 인터넷에서 라우팅이 가능하고 전체에서 유일한 주소
-사설 IP: 공인 IP 내에서만 유일한 주소
-127.0.0.1: 내 컴퓨터

-NAT: 사설IP와 공인IP주소 사이의 주소 변환을 수행 사설IP를 인터넷에 접속시킴

-Port: IP주소가 컴퓨터를 찾는 주소라면, Port번호는 해당 컴퓨터에서 실행중인 서비스를 구분한다.

TCP/UDP: TCP는 전달확인, 순서를 보장하고, UDP는 확인, 순서 보장없이 빠른 전달

DNS: 도메인이름에 대응하는 IP주소를 찾아 연결시킴

LISTEN: 서버가 클라이언트의 요청을 기다리는 상태
방화벽: 서버가 LISTEN 상태여도 방화벽이 차단하면 클라이언트는 해당 서버에 접속 할 수 없다.
