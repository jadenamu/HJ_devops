2주차

-가상화: 하나의 PC위에 여러 운영체제를 구동한다.
-베어메탈: 하나의 PC위에 하나위 OS로 여러 응용프로그램을 동작
-하이퍼바이저: 전통적인 가상화 기술로, 호스트OS로 게스트OS를 구동 
-컨테이너: 호스트OS로 하나로 여러 독립적인 실행환경을 구축

-Git: 버전 관리 시스템. 코드 변경 이력을 기록하고, 이전 버전으로
돌아가기 등 기능으로 코드의 버전을 관리한다.

-branch: 개발환경을 독립시켜 서로 간섭을 줄여준다.

-GitHub: Git 기반의 온라인 협업 플랫폼.


-리눅스 기본 명령어
  -ls: 현재 디렉터리 내용물 확인
  -cd: 디렉터리 이동
  -pwd: 현재 위치 확인
  -mkdir: 디렉터리 생성
  -touch: 파일 생성
  -cat: 파일 확인
  -nano: 파일 수정
 
-git 기본 명령어
  -git init: git 환경 초기화
  -git add: 변경 내용을 staging area에 올림
  -git commit: staging area의 파일등에 체크포인트 지정
  -git push: 커밋된 파일들을 GitHub 레포에 올림
